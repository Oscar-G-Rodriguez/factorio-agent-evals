# One-off development tools

These scripts were used for specific development incidents and are retained for provenance. They are not run by the launchers or tests.

- `record_failed_runs.py` annotated an interrupted early context run and copied two host-local logs. Its input paths refer to the original development workspace.
- `speed_up_live_demo.py` repeatedly changed the speed of an already-running demonstration server.

Use the active tools in the parent folder for new experiments. The scripts here are historical and may require the original host state.
